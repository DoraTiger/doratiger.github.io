前言

实验室服务器升级到 Ubuntu 26.04 后，继续检查了显卡驱动和 CUDA 环境。三台机器的驱动小版本不同，原来的 CUDA 12.6 在新系统上编译程序时又遇到了头文件冲突，因此把驱动、CUDA 和 NCCL 一起进行了统一。

服务器操作指北（12）Ubuntu 26.04 升级与 FreeIPA、K3s、远程桌面适配
创建于 2026-11-15
更新于 2026-11-16
科技
k3s
freeipa
ubuntu
rdma
guacamole

前言

实验室有同学遇到了 FreeIPA 账号认证失败的问题，排查发现服务器此前发生过 OOM，导致 SSSD 等相关服务启动失败。修复认证问题后，正好三台服务器都处于空闲状态，便安排了这次系统升级。

服务器原来使用 Ubuntu 24.04，账号和 sudo 权限由 FreeIPA 统一管理，容器业务运行在 K3s 中，远程桌面通过 Guacamole 连接。考虑到 Ubuntu 26.04 LTS 已经发布了一段时间，稳定性应该相对成熟，我决定利用这次空闲期升级。为了保证升级可靠性，采用逐台升级、逐台验证的方式，避免批量升级导致多台服务器同时出现问题。

之前在 服务器操作指北（5）编译安装 openssh 9.3p1 with openssl3.1.0 中记录过 Ubuntu 20.04 升到 22.04 后，重新编译 OpenSSH、OpenSSL 的处理。这次除了系统升级，还涉及 FreeIPA 授权、GNOME 远程桌面和 K3s 容器，因此把 Ubuntu 24.04.5 升至 26.04.1 的过程和相关适配一起整理。
