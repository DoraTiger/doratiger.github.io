前言

上一篇整理了主题架构，这篇记录配色、背景动画和布局的实现。DoraTiger 最初沿用了 Fan 的暗色风格，后来逐步把颜色和尺寸提取成配置，也尝试用 Canvas 绘制星空和首页文字。现在又补上了日间主题，并给虎头像和迎宾图接入日夜切换。

20261113：补充日夜主题、头像与迎宾图配置，更新配色和动画说明。

一、日夜主题

1.1 从星空到日间背景

DoraTiger 最初继承了 Fan 的暗色风格。用了很久的星空背景已经看习惯了，重构主题时也就保留下来。早先一直没想好亮色背景该怎么做，纯白有些单调，直接换一个渐变又容易和正文抢颜色，所以第一版只有暗色方案。

后来采用了偏暖的纸色作为日间底色，配深墨青文字，背景保留浅天空和太阳。夜间继续用深色星空和月亮。正文卡片、导航、代码块也一起换色，白天看长文章时就多了一个选择。

右上角的日月按钮用于手动切换。没有保存过选择时，主题跟随系统；手动切换后，将选择保存在浏览器的 localStorage 中，下次打开仍沿用上次的模式。

1.2 配色与切换

现在的配色集中在 source/css/_variable/variable.styl 中。主要颜色如下：

用途 日间 夜间
页面底色 #FDF6E3 #020409
正文 #073642 #FFFFFF
次要文字 #586E75 #BAC5E1
内容卡片 半透明纸色 半透明白色

强调色仍保留金色和浅蓝色。金色放在纸色背景上偏浅，日间会混入深墨青，生成更深的交互颜色，避免链接和按钮看不清。

theme-config() 在构建时读取配置，浏览器中的日夜切换则通过 CSS 自定义属性完成。下面省略了边框、代码高亮等颜色：

页面根节点上的 data-appearance 保存 day、night 或 system。组件引用同一组颜色变量，切换时就不用分别改导航、侧栏和正文的颜色。已有的 Stylus 变量也保留下来，例如 $color-text 指向 var(--dt-text)，原来的组件样式可以继续使用。

Canvas 需要另外重绘。主题切换时会发出 doratiger:appearancechange 事件，背景等组件通过事件拿到当前是否为日间模式。

原来的内容区用了半透明白色背景，叠在星空上有一点毛玻璃效果。日间则改成半透明纸色，边框和阴影随配色一起调整：

二、Canvas 动画系统

2.1 星空背景

夜间的全屏 <canvas> 元素 #universe 通过 requestAnimationFrame 绘制星空，包括缓慢漂移的巨星、带拖尾的彗星和普通闪烁星星。画布放在内容下方，不拦截页面交互。

星星数量按窗口宽度计算，小屏幕再减少一些：

javascript
1
2
this.starDensity = 0.216;
this.starCount = this.width * this.starDensity * (this.width < 768 ? 0.45 : 1);

补上日间主题后，星空只在夜间运行。切到日间时取消动画帧并清空画布，切回夜间再恢复。浏览器标签页隐藏时也暂停绘制；系统开启“减少动态效果”时，不启动星空动画。

2.2 Hero 文字渲染

首页顶部的标题和副标题使用 Canvas 渲染，配合 pretext 排版引擎做精确文字布局：

// source/js/layout/hero.js
class Hero {
    resize() {
        const rect = this.canvas.parentElement.getBoundingClientRect();
        this.width = rect.width;
        // 根据容器宽度动态计算字体大小
        const titleFontSize = Math.min(this.width / 10, 64);
        // 使用 pretext 做精确排版（支持自动换行）
        const prepared = prepareWithSegments(this.title, font);
        const { lines } = layoutWithLines(prepared, maxWidth * dpr, lineHeight * dpr);
    }

    draw(progress) {
        // 每行文字渐入动画（stagger + easeOutExpo）
        const lineDelay = line.type === 'title' ? i * 0.08 : 0.4 + i * 0.06;
        ctx.globalAlpha = eased;
        ctx.translate(0, (1 - eased) * 20); // 滑入效果
    }
}

pretext 库是前一阵刷技术博客时偶然发现的，看着能做 Canvas 文字排版就随手加进来了，没有做太多调研。实际用下来基本能用，但在响应式布局上还有一些小 bug（比如侧边栏切换时文字居中计算不准确），目前还没完全修好。

三、响应式布局

3.1 可用宽度与导航布局

早期的导航布局用了 JS 动态计算，根据各区域的实际可用宽度调整元素显示。

导航和侧栏的可用空间不同，读取容器尺寸可以决定哪些元素需要收起。下面保留早期的简化示例；当前布局同时使用 CSS 媒体查询处理断点。

javascript
1
2
3
4
5
6
7
// source/js/layout/header.js
function autoResizeHeaderRight() {
    const containerWidth = headerWrapper.getBoundingClientRect().width;
    // 空间不足时依次隐藏：搜索按钮 → 站点标题 → 时钟
    if (containerWidth < 600) searchButton.style.display = 'none';
    if (containerWidth < 400) titleElement.style.display = 'none';
}

不过移动端的自适应效果一般 — 主要是因为之前开发 Spring Boot + Bootstrap 项目时习惯了容器化排版，对 flex 布局有一种天然的偏好，所以做了自适应。但移动端屏幕尺寸有限，很多在桌面端好看的效果在手机上效果平平，算是一个妥协。

四、可复用动画 Mixin

三个核心 Mixin 覆盖了大部分交互动画场景：

4.1 下划线展开

stylus
1
2
3
4
5
6
7
hover-underline($left = 0)
  &:after
    left $left; width 0; height 0.125rem
    background $color-theme
  &:hover
    &:after
      left 0; width 100%

下划线从指定位置展开到全宽，用于菜单项、链接等。

4.2 四边框动画

四个子元素 .line-top/right/bottom/left，hover 时从外部展开到完整边框。用于统计数字、友情链接等卡片。

4.3 光扫按钮

::before 伪元素实现光扫效果：

stylus
1
2
3
4
5
6
button-hover-effect()
  &::before
    left -100%
    background linear-gradient(to left, rgba(255,255,255,0), rgba(255,255,255,0.5), rgba(255,255,255,0))
  &:hover::before
    left 100%; transition left 0.5s ease

CSS 的动画语法确实绕，尤其是 ::before/::after 伪元素配合 transition 的各种组合，踩了不少坑。最终真正熟练掌握的主要是 Stylus 的变量、Mixin 和函数体系，底层 CSS 动画还是在实践中慢慢摸索出来的。

五、视觉参数配置

最初写样式的时候，颜色值直接散在各个 .styl 文件里：post.styl 写一个，sidebar.styl 再写一个。后来想让主题色可配置，才逐一整理到 _variable/variable.styl 中。

现在常用的强调色、正文字号和布局宽度可以在博客根目录的 _config.hexo-theme-doratiger.yml 中覆盖：

yaml

  accent_secondary: "#73C4F5"

    font_size: "16px"

这些配置在 Hexo 构建时生效。日夜配色的具体搭配、部分间距和动画参数仍由主题样式维护，需要改动时再调整源码。

六、头像与迎宾图

6.1 两种虎形象

之前侧栏用的是蓝色外环的虎头像，关于页开头则放了一张挥手的大白。最近整理个人视觉素材时，保留了虎头的方向，分别做了虎徽和 Q 版虎：侧栏继续用虎徽，关于页换成 Q 版小虎挥手的迎宾图。

两种形象都准备了日夜版本。头像的脸型、虎纹和表情保持一致，主要更换底盘和外环颜色；迎宾图则分别配太阳、云层和月亮、星空。这样切换主题时，角色还是原来的角色，背景能和页面接上。

页面的大面积配色沿用现有主题，虎橙主要留在角色身上。正文继续沿用原来的章节、代码块和图表排版。

6.2 侧栏头像

原来的主题只有一个头像地址，这次新增了两个可选配置：

yaml

global:
  favicon: /images/identity/favicon.svg
  avatar: /images/identity/avatar-share.png

sidebar:
  info:
    avatar:
    avatar_day: /images/identity/badge-emblem-light.svg
    avatar_night: /images/identity/badge-emblem-dark.svg

图片放在博客的 source/images/identity/ 下。主题只提供切换能力，个人素材由博客自己保存，其他人用主题时可以换成自己的图片。

某一侧没有填写时，回退到 sidebar.info.avatar，再沿用 global.avatar；两项都不填，就继续显示原来的单张头像。global.avatar 同时保留 PNG，供默认分享预览使用。

侧栏选用了圆外透明的 SVG 徽章，日夜头像保持相同尺寸。原来鼠标放上去旋转的动画也去掉了，虎头倒着转一圈看起来不太合适。

浏览器标签上的图标另用了简化虎头。完整头像缩到 16 或 32 像素后，虎纹和细环挤在一起，单独准备小图标更清楚。

6.3 关于页图片切换

关于页的迎宾图直接写在页面正文中。两张图片放进同一个容器，由主题 CSS 控制显示：

html
1
2
3
4
5
6
7
8
<div class="appearance-image about-welcome">
  <img class="appearance-image-day"
       src="/images/identity/welcome-light.webp"
       width="720" height="720" alt="小虎挥手欢迎你">
  <img class="appearance-image-night"
       src="/images/identity/welcome-dark.webp"
       width="720" height="720" alt="小虎挥手欢迎你">
</div>

appearance-image 负责日夜切换，about-welcome 负责居中和展示尺寸。它们复用页面已有的 data-appearance 和系统配色媒体查询，不需要额外写一段图片切换脚本。

迎宾原图每张约 1.6–1.8MB，网页上用不到这么大，另存成 720×720 的 WebP 后，两张分别约 64KB 和 76KB。原图继续保留，页面中的显示宽度限制为 240px。

这里还踩了一个 Stylus 的坑。最初想让图片不超过容器，同时限制最大宽度，写成了：

stylus
1
width min(100%, 240px)

结果构建后只剩下 width: 100%。Stylus 提前计算了 min()，没有把它原样交给浏览器。手机竖屏时内容区本来就窄，看起来还算正常，桌面横屏下图片却直接铺满了正文宽度。

最后拆成两个属性：

stylus
1
2
3
4
5
6
7
8
.appearance-image.about-welcome
  width 240px
  max-width 100%
  margin 0 auto 1rem
  > img
    width 100%
    height auto
    margin 0

这样宽屏下是 240px，容器更窄时再随容器缩小。改完分别检查了两个站点的桌面和手机页面，日夜切换时图片尺寸保持一致，个人介绍也能留在首屏里。
