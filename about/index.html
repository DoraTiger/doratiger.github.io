DoraTiger 的异次元

关于我

我是 DoraTiger，也叫“有次元袋的 tiger”，目前在东北大学攻读计算机方向博士，主要关注分布式系统、去中心化系统与区块链。

研究与项目实践中，我参与过基于 Flink 的流计算与批流融合系统、基于 Ray 的分布式计算框架，以及区块链事务处理与数据管理系统的研发。除了核心模块开发，也承担过系统架构设计、性能优化、跨团队技术对接和技术文档组织工作。我比较关心一个想法如何落到具体系统中，以及它在真实约束下如何运行和维护。

平时主要使用 Go，也使用 Java 和 Python。研究之外，喜欢围绕自己的使用需求开发工具、搭建服务，从博客的一个功能到 Homelab 中的一套环境，慢慢把它们调整到顺手、可维护的状态。

这个博客写些什么

这里既有学习笔记，也有部署记录和开发复盘。我会记录做了什么，也尽量说明为什么这样选择、遇到了什么问题，以及还有哪些地方没有解决。

  • 服务器与日常工具实践：较早的“服务器操作指北”“NAS 折腾日记”等系列，记录了服务器配置、自托管应用、存储管理与日常工具使用。这些实践也逐渐延伸成了后来的 Homelab 搭建手记，历史文章保留了当时的环境与版本背景。
  • Homelab 搭建手记：从主机与 Debian 环境开始，逐步整理开发工具、自托管服务和浏览器远程访问。可以从 主机选购与系统安装 或 开发环境一键配置 开始阅读。
  • HEXO 开发笔记：记录这个博客本身的建设，包括自建主题的架构、视觉设计、功能实现与工程维护。主题部分可以从 架构与设计哲学 开始阅读。
  • 研究与学习记录：围绕分布式计算、区块链及实际项目中接触到的技术整理理解，也保留一些生活与折腾记录。其他文章可以在 归档 中找到。

有些文章会促使我把临时配置整理成脚本，有些项目则需要通过文章解释设计取舍。博客与代码一起维护，也方便日后重新理解当时的选择。

正在维护的公开项目

  • hexo-theme-doratiger：为自己的博客开发的 Hexo 主题，也是本站使用的主题。主题设计和实现过程记录在 HEXO 开发笔记系列中。
  • doratiger-counter：面向静态站点的轻量自托管 PV/UV 统计服务，用来承接博客的访问统计需求。相关设计见 自建访问统计。
  • homelab-setup：面向 Debian 的环境配置与服务部署脚本，将日常开发环境和有状态服务的部署过程整理成可重复执行的步骤。Homelab 系列为它补充使用背景与配置原理。

此外，也写过 NEU_IPGW 这样的校园网登录工具。更多公开代码见 GitHub。
